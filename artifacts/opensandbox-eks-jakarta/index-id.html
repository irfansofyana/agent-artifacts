OpenSandbox di EKS Jakarta

OpenSandbox itu sandbox API yang kamu jalankan sendiri. Cluster EKS kecil di Jakarta, dengan runtime container biasa, kira-kira $777/bulan. Layout 2 AZ kira-kira $1,174/bulan, sebelum PPN dan traffic.

English: English version.

Apa ini

OpenSandbox kasih agent sebuah environment Linux terisolasi untuk menjalankan command, mengedit file, dan, kalau tool-nya ada di image, menggerakkan browser atau desktop. Aplikasi kamu bicara ke satu lifecycle API. Server-nya bisa di Docker untuk laptop, atau di Kubernetes untuk cluster. API-nya sama.[1]

Halaman ini dipin ke release-1.2.1, terbit 13 Nov 2026. Situs dokumentasinya masih mencontohkan checkout release-1.1.0. Pakai tag stable, bukan main.[2][3]

Lisensinya Apache-2.0, dan ini proyek Agentic AI Foundation.[1]

Apa yang API-nya kasih

Di release-1.2.1, kelima SDK bisa membuat sandbox, menyambung lagi, memperpanjang, pause dan resume, lalu mematikannya. Mereka bisa menjalankan command, baca dan tulis file, baca metrics, mengatur egress policy, dan memakai Credential Vault. Snapshot, template, volume, dan pool juga ada di SDK. Pause, snapshot, dan template benar-benar jalan atau tidak tergantung runtime di belakang server, bukan di client.[7]

  • Traffic masuk di Kubernetes lewat ingress gateway. Sandbox pod-nya ClusterIP saja, jadi gateway-nya wajib, bukan opsional.[3]
  • Akses keluar adalah policy per sandbox. Credential Vault bisa memanggil layanan luar tanpa menaruh secret aslinya di dalam sandbox.[1]
  • Pool dan batch create dipakai untuk menjalankan banyak trial sekaligus. C# adalah SDK yang tidak punya Client Pool.[7]

Fast Sandbox adalah runtime terpisah, bukan produk kedua. Create yang menyebut template diarahkan ke Firecracker microVM di dalam pod yang sudah dihangatkan, dan id sandbox-nya diawali fsb-. Create berbasis image tetap memakai pod Kubernetes biasa. SDK-nya tidak berubah.[9]

Bagaimana aplikasi lain memakainya

Apa pun yang bisa memanggil lifecycle API bisa memakai cluster ini. Server-nya tidak peduli bahwa dia berjalan di EKS.

  • Service kamu sendiri memakai SDK: Python (opensandbox), TypeScript (@alibaba-group/opensandbox), Java atau Kotlin, Go, atau C# (Alibaba.OpenSandbox). Python adalah bahasa di quick start. Go yang lebih pas untuk backend yang hidup lama.[1][7]
  • Orang atau script memakai CLI osb. pip install opensandbox-cli.[1]
  • Agent yang sudah bicara MCP memakai opensandbox-mcp. Setup yang didokumentasikan adalah Claude Code dan Cursor, lewat stdio atau HTTP. Client MCP lain bisa memakai server yang sama. Tool-nya mencakup create, connect, kill, renew, menjalankan command, dan file teks. Pool, snapshot, template, dan Credential Vault tetap di SDK atau CLI.[6]

Pemakaian kedua, yang beda, adalah menjalankan agent di dalam sandbox. Contohnya melakukan itu untuk Claude Code, Codex CLI, Gemini CLI, OpenCode, Qwen Code, Kimi CLI, OpenClaw, LangGraph, Google ADK, Playwright, Chrome, desktop, dan VS Code Web. Itu workload. Client-nya tetap SDK atau MCP server yang membuat sandbox-nya.[8]

Arahkan client ke lifecycle host dan API key. Untuk CLI itu osb config set connection.domain. Untuk MCP itu --domain dan --api-key.[1][6]

Arsitektur

Diagram ini adalah layout Jakarta yang kecil: client di luar region, load balancer, tiga pod control plane, sandbox pod, ECR untuk image, dan Postgres opsional. EKS 1.35 atau 1.36 adalah batas cluster. Fast Sandbox tidak ada di gambar ini.

Komponen

  • Lifecycle server, satu replica, port 80. Dia menolak start tanpa API key. Upgrade memakai Recreate, jadi API-nya sempat putus.[3][4]
  • Controller, yang merekonsiliasi BatchSandbox, Pool, dan SandboxSnapshot. Ukurannya kecil. Bukan dia yang menentukan ukuran node.[3]
  • Ingress gateway, dua replica, masing-masing request 1 CPU dan 4 GiB, limit 2 CPU dan 8 GiB, listen di port 28888. Service chart-nya ClusterIP di port 80.[5]
  • Sandbox pod di namespace opensandbox. execd ada di dalam image sandbox. Egress sidecar ditambahkan hanya kalau create request mengisi networkPolicy.[4]

Yang harus kamu sediakan

  • EKS 1.35 atau 1.36 di ap-southeast-3. OpenSandbox hanya butuh Kubernetes 1.22+. Jangan buat 1.34: standard support berakhir 2 Des 2026, dan extended support $0.50/jam, $365/bulan, bukan $73.00.[3][11][15]
  • Helm 3, dari git checkout release-1.2.1. Chart tidak diterbitkan sebagai paket terpisah.[3]
  • ECR di Jakarta. Registry default chart adalah sandbox-registry.cn-zhangjiakou.cr.aliyuncs.com. Jangan pull itu dari region ini. Mirror server, controller, ingress, execd, dan egress dari Docker Hub atau GHCR, lalu pin digest-nya. Umbrella release yang sekarang tidak Cosign-signed seperti release per-komponen yang lama.[1][4][13]
  • Secret API key, nama DNS untuk server.gateway.host, dan load balancer di depan server dan gateway.
  • RDS PostgreSQL opsional di region yang sama, kalau reschedule tidak boleh menghapus state sandbox. Default chart adalah satu server dan tanpa database.[3]
  • EBS gp3 kalau sandbox memasang volume. Jalur dasar tidak membutuhkannya di luar disk node.

Contoh

Python, ke server yang sudah berjalan. Panggilan yang sama jalan ke host EKS begitu domain dan API key diarahkan ke sana.[1]

from opensandbox import Sandbox

sandbox = await Sandbox.create("alpine")
try:
    result = await sandbox.commands.run("echo 'Hello OpenSandbox!'")
finally:
    await sandbox.destroy()

Bentuk CLI-nya:

osb config set connection.domain <lifecycle-host>
osb config set connection.protocol https
osb config set connection.api_key <api-key>
osb sandbox create --image python:3.12 --timeout 30m
osb command run <sandbox-id> -- python -c "print(1 + 1)"

Deploy di EKS Jakarta

Biarkan fast-sandbox mati. Panduan cloud mereka minta node bare metal dengan /dev/kvm, dan semua node di pool itu harus CPU model yang sama. Satu c7i.metal-24xl di Jakarta kira-kira $3,606/bulan sebelum disk. Nested virtualization AWS bisa membuka /dev/kvm di m7i, c7i, r7i, dan i7i tanpa biaya tambahan, dan m8i / c8i tidak ada di price list Jakarta, tapi OpenSandbox belum menerbitkan resep EKS untuk jalur itu.[10][12][14]

  1. Buat cluster di 1.35 atau 1.36, di ap-southeast-3, dengan subnet private kalau kamu bisa menerima NAT.
  2. Dua managed node group. Node system menjalankan server, controller, dan gateway. Pilot muat di satu m7i.2xlarge, yang sesuai dengan satu replica server. Worker hanya menjalankan sandbox pod, di-taint, mulai dari satu c7i.2xlarge.
  3. Mirror kelima image ke ECR pada release-1.2.1 dan buat pull secret atau node role yang bisa membaca registry itu.
  4. Buat namespace opensandbox-system dan opensandbox. Chart tidak membuat namespace workload.[3]
  5. Checkout release-1.2.1, jalankan helm dependency build di manifests/charts, lalu install umbrella chart dengan ingress-gateway.enabled=true dan repository image mengarah ke ECR. Simpan API key di Secret dan referensikan dari values server. Isi server.gateway.host dengan nama yang akan dipakai client.
  6. Pasang ALB atau NLB di depan server dan gateway. Pastikan /health jawab sebelum mengarahkan client ke sana.
  7. Tambah RDS hanya kalau state harus bertahan saat pod di-reschedule. Biarkan server.replicaCount di 1. Replica kedua bukan high availability umum.[3]

Tiga public IPv4 di baris 2 AZ adalah asumsi jumlah alamat: satu untuk NAT, dua untuk load balancer yang menghadap internet di dua AZ. Tarif jam-nya dari offer file.

Setiap c7i.2xlarge private tambahan plus 50 GB gp3 kira-kira $305/bulan. Berapa sandbox yang muat tergantung CPU dan memory di create request, bukan di chart.

Yang biasanya mengejutkan adalah jam NAT, bukan gigabyte-nya. 100 GB lewat NAT harganya $5.90. Gateway yang sekadar ada sudah $43.07/bulan sebelum ada traffic sandbox. EKS sendiri $73.00 bahkan dengan dua node.

Kalau kamu tidak ingin mengubah limit 8 GiB di chart, ganti dua system node m7i.xlarge dengan dua m7i.2xlarge. Itu menambah kira-kira $368/bulan. Kubernetes menjadwalkan berdasarkan request, jadi pasangan yang lebih murah muat kalau server dan dua pod gateway tersebar.

Kalau cluster dibiarkan di 1.34 lewat 2 Des 2026, control plane pindah ke extended support dan baris $73.00 menjadi $365, naik $292, tanpa perubahan di OpenSandbox.[11][15]
