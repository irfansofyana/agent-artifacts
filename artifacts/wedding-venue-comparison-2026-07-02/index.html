Decision Notes

Do not mix scopes

Most interesting pairs

  • Aminta Hall + Puspita because package benchmark is lowest.

Watch the ceiling

If the event target stays around Rp200jt excluding rings/seserahan/mahar, package routes above Rp180jt before venue are already danger-zone.
