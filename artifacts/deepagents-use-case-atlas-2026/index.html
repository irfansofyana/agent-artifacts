What people actually build with Deep Agents.

A field guide to LangChain’s deepagents libraries on top of LangGraph: source files, worked tutorials, and real project integrations. Organized around research, coding, data, UI, MCP, memory, and operations—not generic “agentic AI” links.

The take: Learn the TypeScript API from official code, then study a narrow research application before reading a large product. A project’s star count measures the whole repo; it does not certify its Deep Agents integration, security, or production readiness.

Method, evidence and limits

  • Inclusion test: community repositories have an inspected source file importing LangChain’s deepagents or createDeepAgent/create_deep_agent; a name or README mention alone was not enough. No agent runtime in these projects was executed. The exact code links are pinned where available.
  • Ranking: direct working examples and explanatory depth come before stars. Official docs explain the current API; community repos show possible architectures, not endorsed deployments. Repo stars/forks from GitHub API on 24 September 2026 belong to the whole host repository.
  • Engagement: three video view/like displays were read from the original YouTube watch pages on 24 September 2026; rounded likes marked ~. Articles and docs have no public comparable audience metrics, so no readership figure is inferred. “Popularity” sorts only after choosing a single source type.
  • Language and freshness: the primary path is TypeScript. Python showcases are labeled. Some official TypeScript pages carry stray Python identifiers; source code is authoritative for the example and current API docs for the latest signature. Undated pages are not assigned invented publication dates.
  • Safety: a demo, template, or deployment article is not proof of tenancy, permission checks, sandboxing, approval-gated writes, or operational hardening. Review external tool egress and credentials before trying any project.
  • Coverage: 19 official pages/examples, 25 community repositories, 20 tutorials/articles/videos, with one duplicate merged: 63 unique resources. All 63 primary links and 25 direct community code links were checked; reachability is not a code-quality or execution guarantee.

Each resource’s title and source link is its inspectable citation; the implementation claims are tied to the code links or original article beside them. This atlas intentionally excludes Irfan’s own LangGraph course.
