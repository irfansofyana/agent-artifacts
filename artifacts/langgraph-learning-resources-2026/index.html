How to read this atlas

  • Selection: original source inspected for real exercises, code or applied explanation. Rank weighs fit to a hands-on learner, source authority, scope and freshness. Broad high-star toolkits are placed after direct teaching materials.
  • Popularity: GitHub stars/forks came from repository API metadata; video views and displayed likes from the original YouTube watch pages, observed 24 September 2026. Rounded likes are marked ~. Courses and blogs lack public comparable reader counts, so none are invented.
  • Do not compare stars to views: the popularity order is meaningful only after filtering to one kind. Otherwise the list stays ordered by learning fit. Hover a metric for provenance.
  • Version caveat: some strong tutorials are from 2024–25. Recheck APIs against current TypeScript docs before pasting code. “Official” establishes API authority, not real-world performance.
  • Scope: 20 verified repositories + 18 docs/articles/courses + 14 videos/courses, deduplicated to 49 links. It is a curated discovery set, not literally every LangGraph tutorial on the web; no repository from Irfan’s own LangGraph roadmap is included.

All source URLs are linked on the cards; no personal or private course content appears on this public page. Metadata is a point-in-time snapshot and will change.
