The signal rail

Six sprints. One system.

Each sprint follows the same rhythm: acquire the minimum knowledge, apply it immediately, then pass an observable exit gate.

01
LangChain + production-minded RAG

Make retrieval inspectable.

Ingest 15–30 public or synthetic runbooks. Implement chunking, embeddings, semantic retrieval, and cited answers. Compare two chunk sizes and two retrieval strategies.

Watch

  • LangChain components
  • Retrieval and vector stores

Build

  • RAG pipeline
  • Citation display
  • Failure log

Exit gate

  • 10 test questions
  • Inspectable retrieval
  • One measured improvement
02
LangGraph orchestration

Turn a chain into a controlled workflow.

Implement: classify → retrieve → choose tool → execute → verify → answer. Add typed state, timeouts, retries, tool-failure fallbacks, and human approval.

Watch

Build

03
Framework comparison

Rebuild before choosing.

Reimplement one identical workflow with the OpenAI Agents SDK. Keep prompts, tools, and test cases constant; compare control, observability, testability, failure handling, and code size.

Evaluation + hardening

Make quality repeatable.

Create 30 evaluations: 10 retrieval/citation cases, 10 tool-selection cases, 5 unsupported-answer cases, and 5 malformed-input, timeout, or approval-boundary cases.

Recommended stack

Keep the lab deliberately small.

One opinionated baseline

ApplicationPython, LangChain, LangGraph
ModelsOne provider behind a swappable interface
RetrievalA simple local vector store first
ToolsGo MCP server
EvidenceLangfuse traces and evaluations
InterfaceCLI or minimal FastAPI endpoint

Rules of the lab

  1. Never watch more than 45 minutes without implementing.
  2. Use one repository for the entire roadmap.
  3. Update stale course code against current official docs.
  4. Keep a failure log; failures are the curriculum.
  5. Add no new agent framework before the comparison is complete.
  6. Use public or synthetic data only.
Definition of done

The finish line is evidence.

The roadmap is complete when the system can be demonstrated, measured, and explained—not when the watch history is full.
