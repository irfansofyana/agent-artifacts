The recommended direction

Build “calm operator,” not “sci-fi cockpit.”

Use Homepage’s structure, Uptime Kuma’s semantic status colors, and Actual’s visual restraint. The official cockpit proves what is possible; it is not necessarily what will stay useful every morning.

  • One primary accent; neutral surfaces.
  • Green / amber / red only for health and attention.
  • Top row for Today, agents, and cron health.
  • Second row for active work, integrations, and service health.
  • Keep decorative chrome near zero.
